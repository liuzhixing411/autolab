## autolab: cross-model steps
`mcp__codex__codex` and `mcp__codex__codex-reply` do not exist in this lab. Wherever the text above calls them, use the reviewer command instead: `autolab review run <task> <files...>` (add `--claim <C>` for a claim or `--audit <N>` for a novelty audit), or ask the PI to run it when you are a student. Task names: `claim_support`, `experiment_audit`, `kill_argument`, `novelty`, `value_grade`, `idea_review`, `section_review`, `review_loop_round`, `citation_audit`, `paper_claim_audit`, `final_cold_read`. The reviewer reads files only: pass paths, never your own summary. Skip tracing steps (`save_trace.sh`); `state/reviews/` keeps every review. A step that needs some other `mcp__` tool is skipped silently when the tool is absent.
